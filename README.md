# NanoSavo – verkkosivusto

Kuopiolaisen NanoSavon (kylpyhuoneen puhdistus, kalkinpoisto, nanopinnoitus) staattinen, SEO-optimoitu sivusto.

**Teknologiat:** riippuvuukseton Node-generaattori (`scripts/build.mjs`), puhdas HTML/CSS/JS, Netlify Forms, Netlify-hosting.

**Paikallisesti:** `node scripts/build.mjs` → `dist/`, tai `netlify dev`.

**Yhteystiedot:** muokkaa `src/site.config.mjs`.

## Tiekartta
- Oikeat yhteystiedot ja Y-tunnus
- Omat ennen–jälkeen-kuvat kohteista
- Asiakaspalautteet / arvostelut
- Verkkotunnus nanosavo.fi ja Search Console
